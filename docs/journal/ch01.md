# ch01 学员日志（ReAct）

> 三段式（stage-gate 第 9 项）。制作人已填草稿，学员请用第一人称改写「踩坑」段——那是批阅官最看重的一段。

## 学到了什么

- ReAct 的本质是「推理上墙 + 环境反馈回注」：Thought 让错误可观察，Observation 让下一步基于事实。
- 三种失败边界（格式错误/未知工具/步数耗尽）都要「失败关闭」——尤其是步数耗尽，宁可返回未完成，不许假装完成。
- 依赖注入（llm_fn 参数）让测试零成本：16 条测试全程不触网。

## 踩了什么坑（学员改写区）

- （示例）第一次跑真实调用时模型在 Finish 行后多输出了一段解释，被解析器忽略后安然通过——协议解析「取首个匹配」的纪律救了我。
- （示例）温度 1.0 时守协议率明显下降，练习 1 的实验证实了卡点预告 #3。
