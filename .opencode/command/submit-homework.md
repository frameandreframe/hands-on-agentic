按 AGENTS.md 第 5 节执行作业提交流程，参数：$ARGUMENTS（格式：<阶段号> <作业档位：及格|良好|挑战>）

1. 生成提交单（贴在响应顶部）：
   - 阶段 / 档位 / 变更文件清单 / 一句话自述
   - 自查三问：我验证了什么？我没验证什么？我抄了什么、抄自哪里？
2. 跑三道检查并原样贴输出：验证 → 冒烟 → 回测（命令见 AGENTS.md 第 1 节）。任一红即停，不允许带病提交。
3. 题解进 `solutions/` 子仓：ch<N>/exercises-solutions.md（中文讲解+中文注释），主仓不留题解。
4. 学员日志：确认 docs/journal/ch<N>.md 三段齐全，缺失则提示先补。
5. 唤起 @teach-agent 按五段格式批阅；stage-gate 的 PASS 截图/输出一并附上。
